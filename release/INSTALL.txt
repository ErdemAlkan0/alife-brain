A-Life Brain {version}
LLM conversations, long-term memory and trained decisions for Project A-Life NPCs.

REQUIREMENTS
- Project Zomboid Build 42.21 or newer, single player (multiplayer is not supported yet).
- Project A-Life (Steam Workshop).
- Windows 10 or 11.
- The Player2 app (https://player2.game), installed and signed in; it is free.
  Ollama or your own OpenAI key work too (see SETTINGS).

INSTALL
1. Copy the ALifeBrain folder into %USERPROFILE%\Zomboid\mods\
   (you should end up with ...\Zomboid\mods\ALifeBrain\42\mod.info).
2. Get a Player2 client id at https://player2.game/profile/developer
3. Double-click ALifeBrainSidecar.exe once. It creates %LOCALAPPDATA%\ALifeBrain\config.json and
   says the client id is missing. Close it, open config.json with Notepad and put the id here:
   "player2": { "client_id": "YOUR-ID", ... }
   Windows may warn about an unknown app (the exe is not signed): More info -> Run anyway.

PLAY
1. Start Player2, then ALifeBrainSidecar.exe (leave its window open), then the game.
2. In the game's mod list enable Project A-Life and A-Life Brain.
3. Next to an NPC press T, or right-click -> "A-Life Brain: talk to ...". Type and press Enter.
   The game pauses while the conversation window is open. Drag items onto the trade table to trade.
4. The window is in English. Write in the language you like: the NPCs answer in it (English and
   Turkish both work, and other languages the LLM speaks).
5. Options -> Mods -> A-Life Brain: pause while talking, keep the NPCs you meet, and let the
   trained policy choose NPC behaviour (off by default).
Without the sidecar the game and A-Life run as usual; NPCs then use A-Life's own lines.

SETTINGS AND DATA
- Settings, memories and logs live in %LOCALAPPDATA%\ALifeBrain (config.json, memory.sqlite3,
  sidecar.log). Delete that folder to make every NPC forget you.
- Other providers, in config.json: "provider": "ollama" (a local Ollama, model in "ollama") or
  "openai" (your key is read from the environment variable named in "openai": "api_key_env";
  never write the key into the file).
- To remove the mod: turn it off in the mod list and delete Zomboid\mods\ALifeBrain.
